# IEEE-task-0

This project contains Python solutions for a set of programming and data analysis tasks using Python, NumPy, Pandas, and Matplotlib. The tasks include list processing, prime number checking, numerical array operations, student performance data processing, and data visualization.

Prerequisites
The following software and libraries are required:
Python 3.x
NumPy
Pandas
Matplotlib
Git
Install the required Python libraries using:
pip install numpy pandas matplotlib

The programs in this project were personally run using Visual Studio Code (VS Code).
